## 下载

直接下载仓库中的 `YueluoAgent-v1.0.zip`(约 35MB,解压即用)。

## 简介

- **Web 控制台**: 内置 Web 管理界面(SSH / RDP / 定时任务 / 群组会话)
- **多 LLM Provider 支持**: 可配置多个模型供应商
- **Skills 系统**: 可扩展技能目录
- **跨平台**: Windows / Linux 运行时,内置 Python 运行时与 Node 依赖

## 使用

unzip YueluoAgent-v1.0.zip

# 参照包内文档启动
